# 0 Hidden Layers (Logistic Regression)

This directory contains a simple implementation of a neural network with 0 hidden layers. This is essentially equivalent to running 10 logistic regression classifiers in parallel, one for each digit (0-9).

## File Structure

- **`dataGenerator.c`**: 
  - Loads the MNIST dataset (training and testing sets).
  - Initializes a neural network with 784 input nodes (28x28 pixels) and 10 output nodes (digits 0-9).
  - Trains the network using stochastic gradient descent.
  - Saves the learned weights and biases to a binary file named `model.bin`.
  - **New:** Calculates and calculates the prediction accuracy for *each digit* (0-9) on the test set and appends these values to `model.bin`.

- **`visualizer.c`**:
  - Reads the `model.bin` file generated by `dataGenerator.c`.
  - Visualizes the weights for each output node as a 28x28 heatmap.
  - Scales the heatmap up by 10x (280x280) for better visibility.
  - **New:** Reads the per-digit accuracy values from `model.bin`.
  - **New:** Adds a vertical color legend stripe on the right side, showing the mapping from max positive (top) to zero (middle) to max negative (bottom) weights.
  - **New:** Adds a text area below the image displaying the model's confidence/accuracy for that digit (e.g., "Prob: 98.6%").
  - Saves the visualization as `.ppm` image files (`visual_node_0.ppm` to `visual_node_9.ppm`).

## Usage

### 1. Compile and Run the Training Script

This will train the model and save the weights to `data/model.bin`.

```bash
gcc dataGenerator.c -o dataGenerator.exe -lm
./dataGenerator.exe
```

Expected output:
```
Loaded 60000 training images and 10000 test images
Epoch 1: Accuracy = 0.90xxxx, Time = 3.xxxxxx
Test Accuracy = 0.90xxxx
Digit 0 Accuracy: 98.xx%
...
Digit 9 Accuracy: 92.xx%
Updated model.bin with class accuracies.
```

### 2. Compile and Run the Visualizer

This will read `data/model.bin` and generate the visualization images in the `data/` folder.

```bash
gcc visualizer.c -o visualizer.exe -lm
./visualizer.exe
```

Expected output:
```
Generated data/visual_node_0.ppm
Generated data/visual_node_1.ppm
...
Generated data/visual_node_9.ppm
```

## Visualization Output

The generated `.ppm` files visualize what the network has learned for each digit using a "Fire & Ice" color scheme:
- **Black**: Zero contribution (neutral).
- **Red -> Yellow**: Positive weights (Hot). Brighter = stronger positive.
- **Blue -> Cyan**: Negative weights (Cold). Brighter = stronger negative.
- **Right Stripe**: A color legend showing the full range of weight values from positive max (top) to negative max (bottom).
- **Bottom Text**: Displays the test accuracy for that specific digit classification.

You can view these `.ppm` files with most image viewers (like IrfanView, GIMP).
